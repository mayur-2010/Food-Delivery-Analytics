## 📌 Project Overview

The **Food Delivery Analytics Project** is an end-to-end data analytics project that analyzes food delivery operations, customer behavior, restaurant performance, revenue trends, and delivery efficiency.

This project uses SQL, Python, and Power BI to transform raw data into meaningful business insights and interactive visualizations.

**Note:** This project uses a synthetic dataset created for educational and portfolio purposes.

## 🎯 Project Objectives

- Analyze total, delivered, and cancelled orders.
- Calculate total revenue and Average Order Value (AOV).
- Identify top-performing restaurants.
- Analyze city-wise revenue performance.
- Understand monthly revenue trends.
- Identify peak ordering hours.
- Analyze customer ratings.
- Evaluate delivery performance.

## 📂 Dataset Description

The project contains five datasets:

| Dataset | Description |
|---|---|
| customers.csv | Customer information |
| restaurants.csv | Restaurant details |
| delivery_partners.csv | Delivery partner information |
| orders.csv | Food delivery transactions |
| ratings.csv | Customer ratings and feedback |

**Dataset size:**
- Customers: 4,500 records
- Restaurants: 90 records
- Delivery Partners: 420 records
- Orders: 15,000 records
- Ratings: 9,844 records
